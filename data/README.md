# AETHER Data

Data is not yet collected.

## Planned Datasets

- Atmospheric CO2 time series.
- Global annual CO2 emissions.
- Carbon-removal capacity by pathway.
- Clean-energy cost and deployment data.
- Electricity generation and capacity factors.
- Carbon storage capacity estimates.
- Robotics unit cost, production, and deployment data.
- Industrial automation productivity benchmarks.

## Rules

- Keep raw data unchanged in `data/raw/`.
- Put cleaned data in `data/processed/`.
- Use `data/external/` for data that comes from third-party exports or public repositories.
- Document source, download date, license, and transformation steps.
