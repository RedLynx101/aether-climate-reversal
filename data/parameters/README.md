# AETHER Parameter Evidence

This folder holds structured model-parameter evidence for AETHER.

The current file, `aether_parameter_evidence.csv`, is not a polished database yet. It is a working evidence map that forces each model parameter into one of five states:

- `verified_source`: anchored to a source in `references/source-register.md`.
- `derived_from_verified_source`: calculated from a verified source.
- `derived_model_value`: computed from already declared model inputs.
- `generated_model_output`: output from an AETHER model, usually still dependent on hand-set assumptions.
- `scenario_assumption` or `provisional_lead`: useful for modeling but not yet citation-grade.

Use this table to decide what can be cited in the paper, what can only be used as a scenario assumption, and what needs source-backed distributions before outside scientific review.
