# Contributing to AETHER

AETHER welcomes review and contributions from climate scientists, carbon-removal researchers, power-system engineers, geologists, roboticists, economists, measurement specialists, lawyers, governance researchers, and careful generalists.

## Before changing a claim

Open an issue or discussion that identifies the claim, current evidence class, proposed evidence, and expected consequence. Primary sources and reproducible calculations are preferred. Company announcements may be recorded as provisional signals but cannot silently become field evidence.

## Pull requests

Keep each pull request narrow. Include:

- the source or rationale for every changed parameter;
- regenerated tables and figures when model inputs change;
- tests or unit checks for changed calculations;
- a note on whether the result changes a feasibility gate;
- updated manuscript language if a claim changes;
- confirmation that generated artifacts contain no clipped content, orphaned headings, or broken captions.

Run the validation commands in `docs/reproducibility.md` before requesting review. Do not hand-edit generated submission artifacts; change their source or generator and rebuild.

## Research conduct

State uncertainty directly. Separate observation, derivation, assumption, scenario, and speculation. Do not present AETHER as deployed climate infrastructure, a forecast of AI development, or an institution that already exists in law. Preserve the distinction between permitted industrial use inside a measured carbon budget and unlimited atmospheric loading.

Commit history records contribution provenance; manuscript authorship is assigned using ordinary scholarly contribution standards.
