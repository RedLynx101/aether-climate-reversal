# Parameter Evidence Database Notes

Last updated: 2026-06-09

The AETHER model suite now has enough moving parts that citations alone are not enough. The project needs to track which numbers are source-backed, which are derived, which are generated by AETHER models, and which are still hand-set scenario assumptions.

Current files:

- `data/parameters/aether_parameter_evidence.csv`
- `analysis/tables/aether_parameter_evidence_summary.csv`
- `docs/parameter-database-schema.md`

The current table has 34 parameters. It intentionally includes weak entries, including the Figure Robotics X claims and the deep-abundance cost cases, because hiding weak assumptions would make the paper less honest. The point is to label them correctly.

The most important current divide is this:

- Atmospheric CO2, current emissions, current CDR scale, DAC energy range, CO2 splitting thermodynamics, clean-energy cost anchors, IFR robot statistics, and geologic storage context are source-backed.
- The 100 GtCO2/year target, 3 GJ/tCO2 advanced capture scenario, 1 GJ/tCO2 moonshot case, automation-push cost stack, durable-credit ratio, and deep-abundance floor remain scenario assumptions or generated outputs.

The next serious research pass should replace the hand-set cost and uncertainty ranges with sourced distributions, not just better prose.
