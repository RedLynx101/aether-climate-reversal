# Robotics Scaling Model Spec

## Objective

Estimate whether AI-enabled robotics could change the cost and speed of carbon-removal infrastructure deployment.

## Core Variables

- `robot_platform`
- `unit_cost_usd`
- `manufacturing_rate_units_per_month`
- `fleet_size`
- `useful_life_years`
- `operating_hours_per_year`
- `maintenance_cost_usd_per_year`
- `energy_kwh_per_hour`
- `task_productivity_units_per_hour`
- `human_supervision_ratio`
- `downtime_fraction`
- `effective_cost_usd_per_operating_hour`

## Platform Categories

- Humanoid robots.
- Industrial manipulators.
- Autonomous mining equipment.
- Autonomous drilling systems.
- Construction robots.
- Warehouse/logistics robots.
- Inspection drones.
- Sensor and MRV networks.

## First Use In The Paper

The first model should not claim that humanoids solve carbon removal. It should test whether a rapid decline in physical automation cost changes the capital and labor bottlenecks for building and operating removal infrastructure.

## Source Needs

- Unit cost and RaaS pricing.
- Production rates.
- Reliability and uptime.
- Deployment examples.
- Maintenance and integration costs.
- Task-specific productivity.
