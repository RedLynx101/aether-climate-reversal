# AETHER Models

This folder will hold model specs and later executable code.

## Model Families

- `carbon-flow/`: emissions, removals, atmospheric ppm, rebound, durability.
- `cost-curves/`: learning curves, deployment rates, energy and capital costs.
- `robotics-scaling/`: unit cost, fleet growth, duty cycle, productivity, labor substitution, infrastructure acceleration.

## Modeling Standard

Each model should include:

- A short model note.
- Input schema.
- Output schema.
- Unit definitions.
- Assumption table.
- Sensitivity ranges.
- Known omissions.
- Reproducible figure scripts once implemented.
