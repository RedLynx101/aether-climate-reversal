# Reviewing AETHER

AETHER is open for scientific, engineering, economic, legal, and governance review. The most valuable contribution is a falsifiable objection tied to a specific claim, equation, source, or missing constraint.

## Start here

1. Read `manuscript/submission/AETHER_v0.46_working_paper.pdf` for the current argument and regional result.
2. Read `manuscript/submission/AETHER_v0.46_technical_supplement.pdf` for the worked accounting example and model boundaries.
3. Check `docs/CORRECTIONS_v0.46.md`, `docs/REGIONAL_REFERENCE.md`, and `analysis/tables/README.md`. Older scorecards and gate tallies are not current readiness evidence.
4. Use `analysis/tables/aether_ai_scenario_comparison.csv` to see how external AI scenarios are classified.

## Review boundaries

- A scenario is not a forecast unless the source says it is.
- An AI timeline is not a robot field-productivity measurement.
- Gross capture is not durable, creditable, lifecycle-net removal.
- A passing component screen is not a passing integrated system.
- Model outputs inherit their stated assumptions and evidence grades.

## Good review submissions

- identify the exact file, section, row, or equation;
- provide a primary source or reproducible calculation when disputing a parameter;
- state whether the issue changes wording, a range, a gate status, or the headline claim;
- distinguish a fatal flaw from a research gap;
- disclose relevant conflicts of interest.

Open an issue using the review template or submit a pull request that includes regenerated outputs and a short explanation of the evidence change.
