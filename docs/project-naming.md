# Project naming

Canonical title: **AETHER: Atmospheric Engineering Through High-Energy Removal**

Use `AETHER` as the short project name in papers, figures, issue titles, website copy, and public discussion. `aether-climate-reversal` is the repository slug, and `aetherclimate.com` is the canonical public domain. Neither slug replaces the project name.

The earlier phrase “climate reversal research” remains useful as a description of the research category, not as a competing brand.
