# AETHER table status

Last reviewed: 2026-09-05

This directory is an archive as well as a working output location. A CSV being
present, reproducible, or numerically consistent does not make it current
public evidence. The current publication uses only the regional reference
package and its explicitly scoped supporting accounting ledgers. Do not infer a
joint feasibility result by combining rows from separate table families.

## Current reproducible supporting outputs

`scripts/reproduce_research.py --check` regenerates these model families in an
isolated temporary tree and compares them with the checked-in results:

| Family | Current outputs | Status and use boundary |
| --- | --- | --- |
| Pathway accounting inputs | `aether_pathway_portfolio_{allocation,summary}.csv`; `aether_pathway_source_gap_analysis.csv` | Supporting stress-test allocation only; not a jointly feasible portfolio. |
| Storage, MRV, and lifecycle accounting | `aether_storage_lifecycle_{routes,summary}.csv`; `aether_mrv_credit_integrity_{assumptions,by_pathway,summary}.csv`; `aether_lifecycle_emissions_{assumptions,by_pathway,summary}.csv` | Current scalar accounting ledgers. Signed net benefit, credit-eligible tonnes, and MRV buffers are separate layers; these are not time- or species-resolved climate flows. |
| Regional reference benchmark | `aether_regional_reference_{summary,resource_ledger,utility_ledger,failure_cases,invariants}.csv`; `aether_regional_reference_summary.json` | Current public evidence package. It compares ordinary and automation-assisted cases under shared stated physical assumptions. Electricity is an annual envelope, not hourly dispatch; its resource, utility, and failure ledgers must travel with its summary. |
| Audit outputs | `aether_independent_calculation_audit.csv`; `aether_rebound_accounting_thresholds.csv` | Current arithmetic/conservation audit. `review_required` rows are evidence boundaries, not passes. |

## Current but not integrated evidence

`aether_integrated_feasibility_{timepaths,scenarios,bottlenecks}.csv` is a
current, reproducible **partially coupled screening** model. It records
realized-production learning state and does not earn learning from unbuilt
plans. It does not consume compatible regional-reference, lifecycle, MRV, or
field-productivity scenario inputs, so it must not support an integrated or
public feasibility claim.

The regional-dispatch diagnostic outputs (`aether_regional_power_*.csv`) are
also reproducible but are synthetic representative-day diagnostics. They are
not the regional-reference benchmark and are not current public evidence.

## Quarantined carbon and climate outputs

All files in these families are retained as rejected/off-reference diagnostics,
not as current evidence or public concentration/temperature projections:

- `aether_carbon_baseline_diagnostics.csv`
- `aether_carbon_cycle_*.csv`
- `aether_state_dependent_carbon_*.csv`
- `aether_climate_response_*.csv`
- `aether_climate_emulator_*.csv`
- `aether_fair_readiness_*.csv`
- `aether_fair_forcing_*.csv`
- `aether_species_emissions_*.csv`

The quarantine remains in force even where a file was regenerated. In
particular, the zero-future-emissions diagnostic exposes an unresolved
reference-response mismatch. Absolute ppm and temperature trajectories must
not be promoted from these tables.

## Historical or unreconciled outputs

Every table not named above is historical, exploratory, or unreconciled under
the current correction contracts. It may be useful for research provenance but
is not current public evidence and must not be used to derive a new tally,
gate, or headline without a scoped rerun and review.

This explicitly includes `aether_feasibility_gate_scorecard.csv` and
`aether_submission_readiness_gates.csv`. Both contain superseded v0.45-era
values and readiness tallies; neither is regenerated by the supported current
pipeline. Leave them intact as history rather than silently re-running a
stale synthesis against changed contracts.
